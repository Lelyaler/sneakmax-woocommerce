# Sneakmax — WooCommerce Theme

- **Демонстрация интерфейса (Live Demo):** [lelyaler.github.io/Sneakmax/](https://lelyaler.github.io/Sneakmax/)
- **Репозиторий фронтенда:** [github.com/Lelyaler/Sneakmax](https://github.com/Lelyaler/Sneakmax)

Кастомная тема интернет-магазина брендовых кроссовок для WordPress и WooCommerce. Превращает статическую верстку Sneakmax в динамический интернет-магазин с поддержкой каталога товаров, фильтрации по цене и параметрам, модального окна быстрого просмотра и интеграцией с корзиной.

## Особенности темы

- **WooCommerce Integration**: полная поддержка архитектуры WooCommerce (шаблоны, хуки, корзина, карточки товаров).
- **Динамический AJAX-каталог**: вывод товаров через `wc_get_products()`, расчет скидок, отображение цен со старой ценой и фильтрация без перезагрузки.
- **Интерактивный квиз**: пошаговый подбор подходящей пары кроссовок по стилю, размеру и предпочтениям.
- **Быстрый просмотр (Quick View)**: всплывающее модальное окно с деталями модели, галереей фотографий и выбором размеров.
- **Интеграция с 1-Click Checkout & Drawer**: поддержка быстрого оформления заказа и боковой корзины.
- **Оптимизация производительности**: подключение минифицированных ассетов, отложенная загрузка изображений (`loading="lazy"`).
- **HPOS Compatibility**: совместимость с High-Performance Order Storage WooCommerce.

## Структура файлов

```
sneakmax-woocommerce/
├── css/                  # Стили и вендорные CSS-библиотеки
├── data/                 # Начальные данные каталога и изображения
├── fonts/                # Шрифты Intro (Bold, Book, Regular)
├── img/                  # Графика, SVG-спрайты и иконки
├── js/                   # Скрипты каталога, слайдеров и модальных окон
├── footer.php            # Подвал сайта и модальные окна
├── front-page.php        # Главная страница магазина со всеми секциями
├── functions.php         # Хуки, регистрация ассетов, блоков и AJAX-обработчики
├── header.php            # Шапка сайта и мини-корзина
├── index.php             # Базовый шаблон вывода контента
├── page.php              # Шаблон страниц с поддержкой вывода блоков Gutenberg
├── style.css             # Декларация темы и кастомные стили
└── woocommerce.php       # Fallback-шаблон для страниц WooCommerce
```

## Установка и активация

1. Скопируйте папку темы в директорию `wp-content/themes/sneakmax`.
2. В панели управления WordPress перейдите в **Внешний вид → Темы** и активируйте **Sneakmax**.
3. Убедитесь, что плагин **WooCommerce** установлен и активен.
4. Настройте валюту магазина в **WooCommerce → Настройки → Общие**.
